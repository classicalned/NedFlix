# Nedflix

Household disc catalog for binders I–VII.

Live site (after Pages is on): https://classicalned.github.io/NedFlix/

## Upload these files to the repo root

- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- data.json

## Turn on GitHub Pages

Repo → Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save.

## Shared saving (wife / housesitter)

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained.
2. Only this repo: `NedFlix`.
3. Permissions: **Contents = Read and write**.
4. Copy the token.
5. In Nedflix → More → paste token → Save token on this phone.

Or send the token so it can be baked into the page and nobody has to paste it.
